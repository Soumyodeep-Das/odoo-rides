# Application Screenshots Directory

Place your application screenshots in this directory. 

### Recommended Naming Convention:
- `login.png` - Login / Authentication Screen
- `dashboard.png` - Main Dashboard / Home Screen
- `find-ride.png` - Find a Ride & Route Selection Screen
- `available-rides.png` - Matching Available Rides List
- `offer-ride.png` - Offer a Ride Form & Route Preview
- `live-tracking.png` - Real-time Map & Trip Tracking Screen
- `vehicles.png` - Vehicle Management Screen
- `wallet.png` - Wallet & Payment Screen
- `analytics.png` - Reports & Analytics Dashboard

Once added, these screenshots will automatically display in the root [`README.md`](../../README.md).
